## 1. Project Overview

**Project Title:** FreelanceFlow - Freelancer Management SaaS Application

**Problem Statement:**
Freelancers struggle with administrative chaos - using multiple tools for client management, time tracking, invoicing, and finances. FreelanceFlow consolidates all these into a single, professional dashboard.

**Solution:**
A comprehensive B2B SaaS application that helps freelancers manage clients, projects, time, invoices, and finances in one place.

---

## 2. Objectives

1. Build a complete CRUD system for Clients, Projects, and Tasks
2. Implement real-time time tracking with stopwatch functionality
3. Create professional invoice generation with PDF download
4. Develop financial reports with charts (Revenue, Expenses, Profit)
5. Ensure strict data isolation between users (Multi-tenancy)
6. Implement tiered access (Free: 2 clients, Pro: Unlimited)

## 7. Mathematical Logic

### Invoice Calculation
```
Subtotal = Σ (Hours × Rate) for each item
Tax Amount = Subtotal × (Tax Rate / 100)
Total = Subtotal + Tax Amount
```

### Time × Rate = Earnings
```
Project Earnings = Σ (Time Log Duration × Hourly Rate)
```

### Project Burn Rate
```
Burn Rate = Total Hours Logged × Hourly Rate
Remaining Budget = Budget - Burn Rate
```

---

## 8. Key Code Snippet - Invoice Calculation

```javascript
const subtotal = items.reduce((sum, item) => {
  return sum + (item.hours * item.rate);
}, 0);

const taxAmount = subtotal * (taxRate / 100);
const total = subtotal + taxAmount;
```

## 9. Security Implementation

### Data Isolation
Every MongoDB query includes `user: req.user.id`:
```javascript
const clients = await Client.find({ user: req.user.id });
```

### JWT Tokens
- Access Token: 15 minutes expiry
- Refresh Token: 7 days expiry
