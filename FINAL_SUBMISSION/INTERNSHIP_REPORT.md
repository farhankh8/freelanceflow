ABSTRACT

FREELANCEFLOW - AN INTELLIGENT FREELANCE MANAGEMENT SYSTEM

Submitted by: K H Mohammad Farhan (23BCAICD182)
Internal Guide: Ms. Aysha Dilshad
Institute: Yenepoya Institute of Arts, Science, Commerce and Management

This project presents "FreelanceFlow," a comprehensive web-based application developed to help freelancers manage their business operations efficiently. The application is built using the MERN Stack (MongoDB, Express.js, React.js, Node.js) and addresses critical challenges faced by freelancers including scattered client information, manual invoicing, poor time tracking, and financial blind spots.

The system provides centralized client management with complete contact details and status tracking. It enables project tracking with budget management and deadline monitoring. Automated invoice generation includes professional PDF output with GST support for Indian freelancers. Real-time time tracking with stopwatch functionality helps freelancers accurately bill their work hours.

Key features include a financial dashboard with visual charts for revenue tracking, lead and proposal management with pipeline view, expense categorization, and secure authentication using JWT tokens. The application is deployed on Vercel (frontend) and Render (backend), demonstrating production-ready capabilities.

This project demonstrates proficiency in full-stack web development, database design, API development, and cloud deployment, fulfilling the academic requirements for the Bachelor of Computer Application degree.

Keywords: Freelance Management, MERN Stack, Web Development, Invoice Generation, Time Tracking, MongoDB, React.js, Node.js
