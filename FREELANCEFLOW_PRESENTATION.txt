SLIDE 12: CHAPTER 5 - IMPLEMENTATION (System Design)
================================================================================

5.1 SYSTEM DESIGN / ALGORITHMS
-------------------------------

GST CALCULATION ALGORITHM:
1. Calculate subtotal (sum of items)
2. Determine GST type:
   • Intra-state → CGST + SGST
   • Inter-state → IGST
3. Apply tax rate (default 18%)
4. Calculate tax amounts
5. total = subtotal + taxAmount

JWT AUTHENTICATION FLOW:
1. User login with credentials
2. Server validates & generates:
   • Access token (15 min)
   • Refresh token (7 days)
3. Access token in Authorization header
4. On expiry → use refresh token
5. Get new access token

AI PAYMENT PREDICTION ALGORITHM:
• Base risk score: 50
• Days overdue × 5 = additional risk
• Payment rate < 50% → +20 risk
• Invoice > ₹50K → +10 risk
• Risk > 70 = High priority
