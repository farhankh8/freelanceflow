###  🏃‍♂️  |  Quick Start

```bash
# Clone the repository
git clone https://github.com/farhankh8/FreelanceFlow.git
cd FreelanceFlow

# Install dependencies
cd client && npm install
cd ../server && npm install

# Run development
# Terminal 1: Backend
cd server
npm run dev

# Terminal 2: Frontend
cd client
npm run dev
```

###  🔐  |  Environment Variables

```env
# Server (.env)
PORT=5000
MONGODB_URI=mongodb+srv://...
JWT_SECRET=your_jwt_secret
JWT_REFRESH_SECRET=your_refresh_secret
NODE_ENV=development

# Client (.env)
VITE_API_URL=http://localhost:5000
VITE_APP_NAME=FreelanceFlow
```

###  📡  |  API Endpoints

| Method | Endpoint | Description | Auth |
|--------|----------|------------|------|
| POST | `/api/auth/register` | Register new user | No |
| POST | `/api/auth/login` | Login user | No |
| GET | `/api/clients` | Get all clients | Yes |
| POST | `/api/clients` | Create client | Yes |
| PUT | `/api/clients/:id` | Update client | Yes |
| DELETE | `/api/clients/:id` | Delete client | Yes |
| GET | `/api/projects` | Get all projects | Yes |
| POST | `/api/projects` | Create project | Yes |
| GET | `/api/invoices` | Get all invoices | Yes |
| POST | `/api/invoices` | Create invoice | Yes |
| GET | `/api/timelogs` | Get all time logs | Yes |
| POST | `/api/timelogs` | Create time log | Yes |
