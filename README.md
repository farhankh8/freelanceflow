## 🏃‍♂️ Quick Start

```bash
# Clone
git clone https://github.com/farhankh8/FreelanceFlow.git
cd FreelanceFlow

# Install dependencies
cd client && npm install
cd ../server && npm install

# Run
cd server && npm run dev    # Terminal 1
cd client && npm run dev   # Terminal 2
```
